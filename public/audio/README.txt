============================================================
  THƯ MỤC ÂM THANH KÊU SỐ
============================================================

1) TIẾNG SỐ (bạn tự cung cấp - quan trọng nhất):
   so-1.mp3, so-2.mp3, ... so-90.mp3
   Khi số X dừng lại, app phát /audio/so-X.mp3.
   - Số nào chưa có file -> app phát tiếng beep dự phòng (không lỗi).
   - Nên cắt mỗi file ~1-3 giây cho gọn.

2) NHẠC NỀN LÚC QUAY (có sẵn - là 2 file giọng hát bạn gửi):
   nhac-nen-1.mp3, nhac-nen-2.mp3
   Tự phát luân phiên trong lúc quay số trên host và TV.

3) KINH (tuỳ chọn):
   kinh.mp3 - phát khi có người KINH. Không có thì app tự beep.

============================================================
  LƯU Ý
============================================================
- Không dùng giọng đọc máy (speech) nữa.
- Cần Chrome/Edge + bật âm lượng. Trình duyệt chỉ phát tiếng sau
  khi bạn tương tác lần đầu (bấm nút) - chính sách autoplay.
- Restart server hoặc Ctrl+F5 sau khi thêm file.
